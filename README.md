# Hector Valdes Recon Lab

Single-page portfolio. A WebGL stage with a rotary dial for projects, profile, experience, tech stack, and contact.

Open `Hector Valdes Recon Lab.html` in a browser. It loads [Three.js](https://threejs.org/) from a CDN, so it needs a network connection.

Scroll or use the arrow keys to change sections. Press Enter to open the selected file. On a phone, swipe the dial and tap to open.
